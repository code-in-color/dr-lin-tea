# Dr. Lin Tea - Hibiscus Fizz

A minimalist, editorial-style landing page for Dr. Lin Tea's sparkling botanical tea.

## Design

Inspired by Utrecht's clean aesthetic with:
- Black & white color scheme with red accents
- Editorial typography
- Floating product animation
- Responsive design

- `index.html` - Main landing page

## First imagery iteration

The floating hero uses a transparent cutout of `reference.png`. Product imagery and local botanical photography replace the gallery/story placeholders while retaining the original design. Sources and licensing are recorded in `assets/README.md`.

Preview locally with `python3 -m http.server 8000`, then open http://localhost:8000.

The newsletter form is still a scaffold demo and is not connected to an email provider.
